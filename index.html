Current Architecture: Local Engine

Runs deterministic rules on the local home server. 100% offline functionality. Zero cloud exposure.

Hardware Parts

ESP32 board, 6 physical buttons, 4 status LEDs, and a mini piezoelectric buzzer. Low cost and highly durable.

Instant Synchronization

Transmits mood events over local Wi-Fi to the family server; dashboard reflects changes in seconds.

Resilient Fallback

API keys remain secured on the server. If internet fails, the local rule engine keeps working seamlessly.
